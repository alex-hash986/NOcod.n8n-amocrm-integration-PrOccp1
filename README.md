# Автоматизация лидогенерации и интеграция с amoCRM на базе n8n

Сквозной сценарий автоматизации (Data Flow) для мгновенной обработки входящих заявок, их фиксации в аналитической базе данных, регистрации сущностей в CRM-системе и отправки уведомлений в мессенджер.

## 🛠️ Технологический стек и инструменты
* **Платформа автоматизации (iPaaS):** n8n (Self-hosted на VPS).
* **Источник данных:** ReqBin (HTTP-клиент для симуляции отправки веб-форм и API-тестирования).
* **База данных и аналитика:** Google Sheets (Облачные таблицы).
* **CRM-система:** amoCRM (Учет клиентов, создание контактов и ведение сделок).
* **Уведомления:** Telegram Bot API (Мессенджер).

---

## 🔄 Архитектура и движение данных (Data Flow)

Сценарий построен по линейной архитектуре со сквозной передачей данных между узлами:

```text
 [ReqBin / Форма] ➡️ [Webhook] ➡️ [Edit Fields (Set)] ➡️ [Google Sheets] ➡️ [amoCRM: Создать Контакт] ➡️ [amoCRM: Создать Сделку] ➡️ [Telegram Bot]
